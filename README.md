
AI Travel Guide

About the Project

AI Travel Guide is an AI-powered application that helps users get travel information and suggestions using AI.

Technologies Used

- Python
- Flask
- Gemini API
- Murf AI API

Features

- Provides travel suggestions.
- Uses AI to generate responses.
- Helps users plan their trips.

How to Run

1. Download or clone the repository.
2. Install the required dependencies.
3. Configure your API keys in the ".env" file.
4. Run the application.

Note

Keep your API keys private. Do not upload your ".env" file to GitHub.
